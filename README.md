# agent-ai-harness
Le 'harnais' autour du code généré par IA, inspiré de l'entretien Underscore_ / Quentin Adam (Clever Cloud) : tests unitaires, intégration, simulation distribuée, pentest automatique multi-modèles sur chaque commit, triage de bugs par agents. On ne paie plus les développeurs pour écrire du code — on paie pour spécifier, cadrer et tester.
